# Triage 标签

工程技能会使用五类标准 triage 角色。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 标准角色 | 本仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整描述，可交给 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或人工判断 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个 triage 角色时，使用本表中对应的标签字符串。
