# 领域文档

本文件说明工程技能在探索本仓库时应如何读取领域文档。

## 文档布局

本仓库使用单上下文布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## 探索代码前先读

- 根目录 `CONTEXT.md`
- `docs/adr/` 下与当前任务相关的 ADR

如果某些文件暂不存在，可以静默继续，并从当前任务中推断上下文。

## 使用统一领域语言

输出中的领域概念应尽量使用 `CONTEXT.md` 中定义的术语。

重要领域术语包括：

- 随势向北
- 主线
- 二级行业成交金额排名
- 周线方向
- 日线 AB 段
- 日线 BC 调整
- C 点
- D 点
- 当前走势
- 60 分钟转向
- 结构止损
- 应急止损
- 时间止损
- 最高收盘价回撤
- 回测样本
- 未来函数 / look-ahead bias
- 参数优化
- 样本内 / 样本外验证

## 标记 ADR 冲突

如果输出与已有 ADR 冲突，应明确指出冲突，而不是静默覆盖既有决策。
