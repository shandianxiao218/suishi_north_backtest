# ADR-0002：MVP-1 日线收盘级回测范围与可优化参数

## 状态

MVP-1 已接受

## 背景

`随势向北` 回测系统第一阶段目标是先验证策略有效性，而不是直接做激进参数优化。

完整交易系统使用：

- 周线判断大级别方向
- 日线定义 ABCD 结构和 C 点候选
- 60 分钟确认当前走势转向和入场触发

MVP-1 暂时采用日线收盘级代理规则，先验证日线 C 点结构是否具有统计优势。分钟级执行回测放到 MVP-2。

## 决策

MVP-1 采用日线收盘级结构回测，并且只使用组合级回测作为主要验证方式。

### 第一目标

先验证策略有效性，参数优化延后。

### 回测时间范围与样本切分

MVP-1 使用 2018 年至最近完整交易日的数据。

| 区间 | 用途 |
|---|---|
| 2018-01-01 至 2022-12-31 | 样本内：开发规则、调试逻辑、观察参数敏感性 |
| 2023-01-01 至最近完整交易日 | 样本外：验证锁定规则是否仍然有效 |
| 2024-01-01 至最近完整交易日 | 近期窗口：观察当前市场结构适配度 |

约束：

- 样本内可用于开发、排错和少量参数敏感性分析。
- 样本外只能用于验证，不应根据样本外结果反复调参。
- 所有报告必须同时展示样本内、样本外和近期窗口表现。

### 股票池

MVP-1 使用沪深 A 股核心股票池：

- 纳入：主板、创业板、科创板。
- 暂不纳入：北交所。
- 排除：ST、*ST、退市整理股票。
- 排除：长期停牌股票。
- 排除：上市不足 120 个交易日的新股。
- 排除：低流动性股票。
- 回测报告必须明确标注 MVP-1 存在幸存者偏差限制。

### 数据颗粒度

MVP-1 使用：

- 周线：方向过滤。
- 日线：AB、BC、C 点代理、信号生成和退出。

MVP-2 可加入 60 分钟 K 线，用于真实当前走势转向和入场模拟。

### 买入执行

- T 日收盘后生成信号。
- 只能使用 T 日及以前可获得的数据。
- T+1 交易日开盘尝试买入。
- 如果 T+1 停牌、无开盘价、一字涨停无法买入，则跳过该交易。
- 仓位和止损按实际买入价计算。

### 交易成本与滑点

MVP-1 使用保守但不过度苛刻的默认交易成本模型：

| 成本项 | 默认值 |
|---|---:|
| 佣金 | 单边 0.03%，买卖都收 |
| 印花税 | 卖出 0.05% |
| 过户费 | MVP-1 先忽略，或并入佣金 |
| 买入滑点 | 0.05% |
| 卖出滑点 | 0.05% |

成交价规则：

- 买入成交价 = 开盘价 × 1.0005。
- 卖出成交价 = 开盘价 × 0.9995。
- 每笔交易必须单独记录佣金、印花税、滑点成本和总交易成本。
- 报告应同时展示扣费前和扣费后绩效，但策略有效性以扣费后结果为准。

### 日线代理 C 点规则

MVP-1 用日线止跌转强行为代理完整系统中的 60 分钟当前走势转向。

默认规则：

- AB 涨幅：A 到 B 至少上涨 20%。
- BC 回撤：B 到 C 回撤不超过 AB 涨幅的 60%。
- C 点窗口：C 在 B 后 3-20 个交易日内形成。
- 止跌转强信号：收盘价站上 5 日均线，或连续 2 日收盘价不创新低。
- BC 阶段量能收缩在 MVP-1 中作为评分项，不作为硬过滤。
- 信号日收盘价距离 C 点低点不超过 8%。
- 周线过滤：周线方向不弱，或至少站上 20 周线。
- 年线过滤：排除年线以下的长期弱结构。

### 主线代理

MVP-1 使用二级行业成交金额排名作为机械化主线代理。

- 强主线：某二级行业成交金额连续 3 个交易日进入前 5 名。
- 观察主线：某二级行业成交金额在最近 5 个交易日内至少 3 次进入前 5 名。
- 启动日：某二级行业首次进入前 5 名；仅记录，不作为已确认主线硬过滤。

MVP-1 的主线过滤轨使用“强主线”定义。

### 回测轨道

MVP-1 至少输出两条组合级回测轨道：

1. 纯结构组合轨：周线 + 日线 ABCD + C 点代理，不使用主线过滤。
2. 主线过滤组合轨：纯结构轨 + 二级行业成交金额强主线过滤。

### 基准指数与对照

MVP-1 至少对比以下指数基准：

| 基准 | 用途 |
|---|---|
| 沪深300 | 大盘核心资产基准 |
| 中证500 | 中盘股票基准 |
| 中证1000 | 小盘与高弹性股票基准 |

报告要求：

- 展示策略组合与三个基准的累计收益、年化收益、最大回撤、收益回撤比。
- 展示样本内、样本外、近期窗口三个区间内的策略相对基准表现。
- 策略有效性不能只看绝对收益，还要看是否优于合理基准，或在相近收益下显著降低回撤。
- 后续可增加全 A 等权代理，但 MVP-1 不强制实现。

### 组合级回测规则

MVP-1 不做单票独立信号统计作为主要结论，只使用组合级回测来评价策略有效性。

组合级规则：

- 初始资金默认 100 万。
- 单笔风险默认 1% 账户权益，可在后续优化中测试 0.5%-1%。
- 最大同时持仓 3 只。
- 每日最多新开 1 笔。
- 每周最多新开 2 笔。
- 已达到最大同时持仓时，新的买入信号全部跳过，不换仓。
- 同一股票已持仓期间，重复信号忽略。
- MVP-1 暂不限制同一二级行业持仓上限，允许主线集中。
- 同日多个候选同时出现时，只选择排序最高的候选。
- 排序优先级：主线确认强度、二级行业成交金额排名、个股成交额、距离 C 点低点更近、BC 回撤更健康、周线方向更强。
- 所有未成交、跳过、顺延卖出的原因必须记录到交易日志。

组合级报告必须输出：资金曲线、回撤曲线、持仓明细、成交明细、跳过交易明细、年度表现、样本内/样本外表现、纯结构组合轨与主线过滤组合轨对比、指数基准对比。

### 退出规则

- 结构止损：跌破 C 点低点。
- 应急止损：从实际买入价下跌 5%。
- 时间止损：买入后 3 个交易日内没有出现浮盈则退出。
- 第一目标：触及 B 点或 2R 时记录为第一目标达成，但 MVP-1 不强制全仓卖出。
- 趋势退出：收盘价从持仓以来最高收盘价回撤至少 8% 时退出。
- 硬最大持仓：30 个交易日。
- 卖出执行：退出信号出现后的下一个交易日开盘卖出。
- 如果停牌或一字跌停无法卖出，则顺延到可执行日。
- 同日多个退出信号同时出现时，采用保守优先级：结构/应急止损、时间止损、趋势退出、硬最大持仓。

### 策略有效性评价指标

MVP-1 不以单一收益率判断策略有效。

有效性判断以组合级表现为主，分为三组指标：

#### 结构有效性

| 指标 | 判断目的 |
|---|---|
| 组合入场后 5 日持仓最大有利波动 MFE | C 点结构是否带来短期正向空间 |
| 组合入场后 10 日持仓最大有利波动 MFE | C 点结构是否具备阶段延续性 |
| 第一目标达成率 | 持仓是否经常回到 B 点或达到 2R |
| 相对随机入场组合优势 | 排除单纯市场上涨导致的假优势 |

#### 交易绩效

| 指标 | MVP-1 参考门槛 |
|---|---:|
| 胜率 | 不单独作为核心，但应尽量高于 45% |
| 平均盈亏比 | 大于 1.2 |
| Profit Factor | 大于 1.2 |
| 收益回撤比 | 越高越好，需与基准对比 |
| 最大回撤 | 必须与指数基准、纯结构轨和主线过滤轨对比 |
| 单笔收益分布 | 避免只依赖极少数异常大赚样本 |

#### 稳健性

| 指标 | 判断目的 |
|---|---|
| 分年度表现 | 不能只靠单一年份贡献收益 |
| 分市场环境表现 | 区分强市、震荡市、弱市 |
| 样本内 / 样本外表现 | 参数不能只在样本内有效 |
| 主线过滤轨 vs 纯结构轨 | 主线过滤后应改善胜率、盈亏比或回撤 |
| 策略 vs 指数基准 | 策略应优于沪深300、中证500、中证1000中的合理对照，或在收益相近时显著降低回撤 |

策略有效的工作定义：

> 组合级资金曲线在样本外仍然保持可解释的正期望或更优回撤控制，并且主线过滤能改善交易质量；而不是单纯追求样本内最高年化收益。

### 后续可优化参数

以下 MVP-1 默认值均记录为后续可优化参数：

| 参数 | MVP-1 默认值 |
|---|---:|
| AB 最小涨幅 | 20% |
| BC 最大回撤 | AB 涨幅的 60% |
| B 后 C 点窗口 | 3-20 个交易日 |
| 信号日收盘价距离 C 点低点最大幅度 | 8% |
| 应急止损 | -5% |
| 时间止损 | 3 个交易日无浮盈 |
| 最高收盘价回撤退出 | 8% |
| 硬最大持仓 | 30 个交易日 |
| 主线确认 | 二级行业成交金额连续 3 日前 5 |
| 观察主线确认 | 近 5 日内至少 3 次进入前 5 |
| 新股排除 | 上市不足 120 个交易日 |
| 单笔账户风险 | 1% |
| 最大同时持仓 | 3 只 |
| 每日最多新开仓 | 1 笔 |
| 每周最多新开仓 | 2 笔 |
| 初始资金 | 100 万 |
| 佣金 | 单边 0.03% |
| 卖出印花税 | 0.05% |
| 买入滑点 | 0.05% |
| 卖出滑点 | 0.05% |
| 指数基准 | 沪深300、中证500、中证1000 |

## 后果

MVP-1 可以先验证日线 C 点结构在真实组合约束下的统计边际，而不被分钟级执行建模拖慢。

由于只做组合级回测，结果更接近真实资金曲线，但也会受到候选排序、交易频率、仓位管理、交易成本、持仓冲突和基准选择的影响。因此所有排序规则、费用明细、基准对照和跳过交易原因必须可审计。

系统必须明确标注：MVP-1 是日线代理研究结果，不等同于完整实盘交易系统。

未来任何参数优化都必须比较样本外表现，不能只接受样本内收益更高的参数。
